# Coven Hollow

A Hobbiton-inspired Halloween witch village, built at 3/4 scale in a front yard in the shadow of the Wasatch. Early Victorian throughout: flame-warm light, gilt serif signage, nothing visibly newer than 1845.

## What's here

- **witch-village-planner.html** — the master planning grimoire: draggable village map, resident roster, immersion ideas, all 11 build sheets with concept art, upgrade sheets for the year-one builds, the Prop Shop recipe library, and the year-round antique hunting list.
- **bakery-3d.html** — interactive 3D build model of the Cackle Crust Bakery. Orbit, zoom, explode the panels apart, toggle the foam skins off to see the lumber frame.
- **bakery-master-packet.md** — the full bakery construction packet: complete shopping list, per-panel cut schedule, ten build sessions, XPS field notes.
- **coven-hollow-build-plans.html** — standalone copy of the seven original construction sheets with dimensioned drawings.
- **coven-hollow-prompt-pack.md** — image-generation prompts for concept art, with revision notes.
- **patio-concepts.md** — four candidate concepts for the patio (drying yard, broom docks, night bazaar, coven hall).
- **index.html** — a small hub page linking to everything (this becomes the homepage if GitHub Pages is enabled).

## Village standards

Roughly 3/4 scale with functional parts near full size. Four finished sides on anything visitors walk around. Pin-hinge panel construction so buildings fold flat in November. Anchored past canyon gusts. Every cord, timer, and fog machine hidden. No one burns anything near foam, ever.
